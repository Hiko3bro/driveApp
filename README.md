# ドライブ発見アプリ (drive-discovery-app)

## コンセプト

このアプリは「行き先を決めるためのアプリ」ではありません。

**何気ない時間や移動を、新しい発見と思い出に変えるアプリ**です。

特に重視しているのは、旅行先で土地勘がないユーザーが、レンタカーの返却時刻や残り時間から、景色の良い道・穴場・寄り道を含むルートを見つけられる体験です。目的地ありきの効率的なナビではなく、「移動そのもの」を楽しくすることを目指します。

## 提供する価値

- 移動時間そのものを、発見と体験の時間に変える
- 「返却時刻まであと〇時間」といった制約の中で、無理なく楽しめる寄り道を提案する
- 土地勘がない場所でも、安心して寄り道を選べる
- 偶然の発見(セレンディピティ)を後押しする
- 移動の記憶を思い出として残せるようにする

詳しいプロダクト定義は [docs/PRODUCT.md](./docs/PRODUCT.md) を参照してください。

## 主な機能

現在実装済みなのは、以下の一連の流れ(縦断機能)です。

- **ホーム** — アプリのコンセプトと4つの入口(今からドライブ/旅行先で探す/みんなのドライブ/記録を見る)を表示。今回操作できるのは「今からドライブ」のみで、他は準備中の表示になります
- **出発地点を選ぶ** — 現在地(位置情報の許可・拒否どちらもハンドリング)、自宅(初回は地図で登録、以降はexpo-secure-storeに保存した座標を再利用。登録済みの自宅は「自宅を変更」で登録し直せます)、地図で指定した場所、の3通りから選べます。地図での確定時は、その瞬間のネイティブカメラ中心を検証して使用します
- **ドライブ条件を入力する** — 使える時間・気分・帰着地点・帰着時刻(目安)・寄り道の量を選び、使える時間と帰着期限の短い方を時間予算としてルート提案処理に渡します
- **3つのルートを提案する / 地図上でルートを比較する** — モックデータで「景色重視」「寄り道重視」「短時間」の3ルートを提案し、地図上のPolylineとカードの横スワイプで見比べます
- **ルートを決定する** — 「このルートにする」を押すと、選択したルート名・距離・所要時間・特徴を表示するルート決定確認画面(`app/route-summary.tsx`)へ進みます(戻る操作でルート比較画面へ戻れます)

> 位置情報・ルート検索は現時点ではすべてモックデータと端末機能(expo-location / expo-secure-store)で実装しており、Google Routes API・Google Places API・Supabase等の外部有料サービスとはまだ接続していません。

今後実装を予定している機能は以下の通りです。

- 実際の道路データに基づくルート検索(Google Routes API等への差し替え)
- 住所からのスポット検索(Geocoding API等への差し替え)
- 発見した場所・移動の記録(思い出化)、みんなのドライブ、旅行先モード

## 技術構成

- [Expo](https://expo.dev) (SDK 54)
- React Native / TypeScript
- [expo-router](https://docs.expo.dev/router/introduction/) によるファイルベースルーティング(スタックナビゲーション)
- `react-native-maps` … 地図表示・ルートのPolyline表示・場所指定のため追加(iOS/Androidのみ対応。Web版では未対応のためプレースホルダー表示になります)
- `expo-location` … 現在地の取得のため追加(許可ダイアログの表示、許可/拒否のハンドリング)
- `expo-secure-store` … 自宅座標を端末内に安全に保存するため追加(住所文字列ではなく緯度・経度を保存)
- 現時点では有料の外部API(Google Routes, Google Places, Supabase, AI API等)は未使用です。UIとルート取得ロジックの間には `RouteProvider` / `GeocodingProvider` という差し替え可能な層を設けており、モック実装(`MockRouteProvider`)から将来のAPI連携実装へ差し替えられる構造にしています

技術方針の詳細は [docs/ARCHITECTURE.md](./docs/ARCHITECTURE.md) を参照してください。

## 起動方法

```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動
npx expo start
```

起動後、ターミナルの案内に従って以下のいずれかで開けます。

- [Development build](https://docs.expo.dev/develop/development-builds/introduction/)
- Android エミュレータ
- iOS シミュレータ
- [Expo Go](https://expo.dev/go)

### iOS Expo Goでの確認手順

1. `npx expo start` を実行する
2. 表示されたQRコードを、スマートフォンにインストールした [Expo Go](https://expo.dev/go) アプリで読み取る
3. ホーム画面から「今からドライブ」→ 出発地点を選ぶ → ドライブ条件を入力する → ルートを比較する → ルート決定確認画面、まで一通り操作できることを確認する
4. 現在地を選ぶ際に表示される位置情報の許可ダイアログで「許可」「拒否」の両方を試し、拒否してもエラー画面にならず、再試行や他の出発地点の選択に進めることを確認する
5. **(iOS実機・確認済み)** ルート比較画面でルートを切り替えてもクラッシュせず、各ルートを選択できることを確認する
6. (確認済み)出発地点を「現在地」で選んで条件入力画面まで進んだあと、戻るボタンで出発地点選択画面に戻り、読み込み表示が固まらず操作できることを確認する
7. **(iOS実機・確認済み)** 出発地点選択画面で、自宅登録済みの状態から「自宅を変更」を押し、地図を動かして登録する。地図操作でクラッシュせず、変更後の自宅が保存されることを確認する
8. **(iOS実機・確認済み)** 「指定した場所」を押し、地図を動かして確定できることを確認する
9. **(iOS実機・確認済み)** ルート比較画面で「このルートにする」を押すと、ルート決定確認画面へ進めることを確認する
10. **(再確認項目)** ルート決定確認画面で「ルート比較に戻る」(または画面の戻る操作)を押すと、正しくルート比較画面に戻れることを確認する
11. **(再確認項目)** 出発地点を「指定した場所」で選んだ場合に、ルート決定確認画面まで進んでも出発地点選択画面の地図ピッカーが勝手に再表示されないことを確認する
12. **(再確認項目)** 1時間・寄り道多めで提案された全ルートが60分以内であることを確認する。過去の帰着時刻、または帰着まで10分未満になる時刻を選ぶと、条件変更を促す日本語メッセージが表示されることを確認する
13. **(再確認項目)** 現在地取得中にヘッダーまたは端末の戻る操作で画面を離れ、取得完了後に条件入力画面や出発地点選択画面が勝手に開かないことを確認する
14. **(iOS再確認項目)** 地図中心取得中・自宅保存中にiOS戻るジェスチャーまたはヘッダー戻るを行っても画面を離れず、処理完了後は通常どおり遷移または戻る操作ができることを確認する
15. **(iOS再確認項目)** 日付変更線をまたぐルートが、世界全体ではなく最小の経度範囲で表示されることを確認する

> react-native-mapsはWeb未対応のため、地図・ルート比較の見た目は正式な検証対象であるiOS実機で確認してください。`npx expo start --web` はビルドが通ることの確認用で、Web版では地図部分がプレースホルダー表示になります。Androidは将来対応予定で、現時点では未検証・動作保証対象外です。

## 現在の進捗

ホーム→出発地点選択→ドライブ条件入力→ルート比較→**ルート決定確認**、までを実機で通して操作できる最初の縦断機能を実装しました。ルート提案・地図データはすべてモックです。

これまでExpo Goでの実機確認で見つかった不具合を修正しています。地図で選んだ場所は確定時のネイティブカメラ中心から取得し、自宅保存中はネイティブの戻る操作による画面離脱も防止します。ルート比較の地図範囲は日付変更線をまたぐ経路も近い地点として計算します。モックルートは帰路を含む全体が時間予算内になるよう生成します。**iOS実機では、自宅変更・保存、地図操作、指定場所選択、ルート切り替え、ルート決定確認画面への遷移を確認済みです**。

- (1回目・確認済み)ルート比較画面で3つ目のルート(短時間ルート)を選ぶとクラッシュする / 条件入力画面から戻ると現在地取得が終わらない
- (2回目以降・iOS主要操作確認済み)自宅変更・指定場所は確定時のカメラ中心を使用し、座標の有限性と緯度経度範囲を検証。非同期処理のキャンセル、帰着期限を含む時間予算、生成座標の正規化も追加しました

日々の詳細な進捗は [docs/PROGRESS.md](./docs/PROGRESS.md)、ユーザーに見える変更は [CHANGELOG.md](./CHANGELOG.md) に記録しています。

## 既知の制限

- ルート提案はすべてモックデータで、実際の道路形状とは一致しません
- 住所からの場所検索は未実装です(地図上での直接指定のみ対応)
- Web版では地図(react-native-maps)がプレースホルダー表示になり、ルートの視覚的な比較はできません
- Androidは将来対応予定です。React Native / Expoによる対応可能な構造は維持していますが、実機未検証のため現時点では動作保証しません
- 有料の外部API(Google Routes, Google Places, Supabase, AI API等)とは未連携です
- ネイティブアプリのビルド設定(iOS/Android)はデフォルトのままです

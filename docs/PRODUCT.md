# プロダクト定義

## 対象ユーザー

- 土地勘のない場所を訪れる旅行者。特にレンタカーを利用し、返却時刻という制約の中で移動するユーザー
- 通勤・買い物など、日常の移動時間を少しでも楽しく・有意義にしたい人
- 「最短ルート」よりも「発見」や「体験」を重視する人

## 利用シーン

### 日常利用

- 通勤や買い物などの何気ない移動の途中で、近くにある新しいスポットに気づく
- ちょっとした空き時間に、無理のない範囲で寄り道を楽しむ

### 旅行先利用

- レンタカー返却までの残り時間から、無理なく寄り道できる範囲・時間を提示する
- 土地勘がなくても安心して選べる、景色の良い道や穴場スポットを提案する
- 「目的地に向かう途中」ではなく、寄り道そのものを前提としたルート体験を提供する

## プロダクトの7つの価値

1. **目的地ではなく体験を起点にする** — どこに行くかではなく、何を体験するかを起点に提案する
2. **制約を前提にした現実的な提案** — 残り時間・返却時刻など、実際の制約の中で成立する提案をする
3. **土地勘がない不安を軽減する安心感** — 知らない土地でも、迷わず安心して選べる情報を提供する
4. **偶然の発見(セレンディピティ)を後押しする** — 検索して探すのではなく、出会う体験を作る
5. **移動そのものを思い出に変える** — 移動時間を「消費される時間」ではなく「思い出になる時間」にする
6. **シンプルで迷わない操作性** — 複雑な条件設定を要求しない、直感的な体験にする
7. **プライバシー・位置情報の慎重な取り扱い** — 位置情報や移動履歴などの個人情報を最小限かつ慎重に扱う

# 設計判断記録(Decision Log)

重要な設計判断とその理由を記録します。新しい決定は末尾に追記してください。

## 記録フォーマット

```
### YYYY-MM-DD: タイトル
- 背景:
- 決定:
- 理由:
- 代替案:
```

---

### 2026-08-30: Claude Code / Codex / GitHub 共同開発のためのドキュメント基盤を整備

- 背景: 複数のAIエージェント(Claude Code, Codex)とGitHub上で安全に共同開発するための共通ルール・ドキュメントが存在しなかった
- 決定: README.md / AGENTS.md / CLAUDE.md を整備し、docs/PRODUCT.md, docs/ARCHITECTURE.md, docs/DECISIONS.md, docs/PROGRESS.md, CHANGELOG.md, .env.example を新規作成する
- 理由: mainブランチへの直接変更や秘密情報の誤コミットを防ぎ、進捗・設計判断を一貫した場所に記録することで、複数エージェント・複数セッションをまたいだ協業を可能にするため
- 代替案: すべてを1ファイルに集約する案もあったが、GitHubや進捗確認アプリで表示されるREADME(現在の正しい状態のみを保つ)と、詳細な作業履歴(PROGRESS.md / CHANGELOG.md)とでは求められる粒度・更新頻度が異なるため分離した

### 2026-08-30: 有料APIを現時点で導入しない

- 背景: Google Routes / Google Places, Supabase, AI APIなど有料サービスの利用が将来的に想定される
- 決定: 現時点ではこれらを導入せず、無料の範囲・モックデータ・ローカル状態管理で機能検証を進める
- 理由: コスト発生と外部依存を避けつつ、先にUI/UX・情報設計・体験そのものを固めるため
- 代替案: 早期にAPIを導入し実データで検証する案もあったが、コスト管理とスコープ管理の観点から現時点では見送った
